# 大政奉還 — 二条城

慶応三年十月、将軍徳川慶喜が二条城で家臣たちと評議を重ね、
大政奉還の決断に至るまでを描く対話型サウンドノベル。

## プレイ方法

GitHub Pagesで公開後、URLにアクセスするだけです。

AIサービスを選択し、APIキーを入力して「開始」を押してください。
デモモードならAPIキーなしで体験できます。

## 対応AIサービス

| サービス | 状態 |
|---|---|
| Gemini（無料版） | 推奨 |
| Gemini（有料版） | 最高品質 |
| MiMo | 高品質 |
| ChatGPT | 安定・制限あり |
| Claude | 制限あり |
| Groq | 無料・高速 |
| OpenRouter | 無料モデル自動切替 |
| デモモード | APIキー不要 |

## 画像の差し替え

`images/` フォルダに画像を入れるとシルエットが差し替わります。
